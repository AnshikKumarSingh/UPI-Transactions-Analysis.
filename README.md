# 💳 Digital Payment Dashboard | Power BI Project

## 📌 Project Overview

The **Digital Payment Dashboard** is an interactive data visualization project designed to analyze UPI transactions, payment performance, transaction amounts, and customer usage patterns. It provides a consolidated view of digital payment activity through interactive KPIs, charts, and filters.

The dashboard helps users understand transaction trends, compare payment methods, evaluate transaction success and failure rates, and explore city-wise payment values and age-group usage.

## 🎯 Project Objectives

- Monitor overall digital payment transaction performance.
- Analyze monthly transaction trends and transaction amounts.
- Compare transaction amounts across banks.
- Track successful and failed transactions.
- Evaluate payment method performance.
- Compare transaction values across cities.
- Understand UPI usage across different age groups.

## 📊 Dashboard Highlights

### 1. Key Performance Indicators (KPIs)

The dashboard displays the following key metrics:

- **Total Transactions:** 20K
- **Total Transaction Amount:** 19.87M
- **Failed Transactions:** 4,000
- **Successful Transactions:** 16K
- **Average Transaction Amount:** 993.61

### 2. Monthly Transaction Trend

Visualizes transaction activity throughout the months to identify changes in transaction volume and monthly patterns.

### 3. Transaction Amount by Bank

Compares transaction amounts across different banks, including:

- HDFC Bank
- SBI Bank
- Axis Bank
- ICICI Bank

### 4. Transaction Success Rate

Provides a visual comparison of successful and failed transactions.

- **Success Rate:** 80%
- **Failure Rate:** 20%

### 5. City-wise Transaction Value

Analyzes transaction values across four major cities:

- Mumbai
- Delhi
- Hyderabad
- Bangalore

This comparison helps identify differences in digital payment values across locations.

### 6. Payment Method Success vs. Failure

Compares the performance of different payment methods:

- Phone Number
- QR Code
- UPI ID

The visualization highlights the success and failure percentages for each payment method.

### 7. UPI Usage by Age Group

Examines transaction activity across different customer age groups:

- 18–25 years
- 26–35 years
- 36–45 years
- 46–60 years

This provides an overview of how digital payment usage varies across age groups.

## 🎛️ Interactive Filters

The dashboard includes filters for:

- Transaction Status
- Bank Name Sent
- Date Range
- City
- Payment Method

These filters allow users to explore transaction data based on their selected criteria.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** — Dashboard development and data visualization
- **Data Visualization** — Interactive charts, KPI cards, and performance indicators

## 💡 Key Insights

Based on the dashboard's displayed metrics:

- Successful transactions account for approximately 80% of total transactions.
- Failed transactions account for approximately 20% of total transactions.
- HDFC Bank and SBI Bank show the highest displayed transaction amounts among the four banks.
- Mumbai has the highest displayed city-wise transaction value.
- The 46–60 age group has the highest displayed usage count among the four age groups.
- Phone Number, QR Code, and UPI ID payments each show success rates close to 80%.

This project demonstrates the use of interactive dashboards to monitor digital payment performance, compare transaction categories, and present business metrics in an accessible visual format.

It showcases practical skills in dashboard design, KPI monitoring, data visualization, and analytical storytelling.
